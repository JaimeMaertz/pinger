# Contributing

Bug reports, device output that doesn't parse, and pull requests are welcome.

## Before you open a pull request

- Run the tests (`go test ./...`) and make sure they pass.
- Keep real network data out of the repository: no real MAC addresses, serial numbers,
  hostnames, passwords or client names in code, tests or fixtures. Made-up values are fine.
- Keep a change focused on one thing, and say in the pull request what it fixes or adds.
